# 🍕 Pizza Sales Analysis — Power BI Dashboard

![Power BI](https://img.shields.io/badge/Power%20BI-Data%20Analytics-F2C811?style=for-the-badge\&logo=powerbi\&logoColor=black)
![Data Analysis](https://img.shields.io/badge/Data%20Analysis-Visualization-blue?style=for-the-badge)

An interactive **Power BI dashboard** built to analyze pizza sales data and provide clear insights into sales performance, orders, products, and customer preferences.

This project demonstrates practical skills in **data analysis, data cleaning, DAX, data visualization, and dashboard design** using Microsoft Power BI.

---

## 📌 Project Overview

The objective of this project is to transform raw pizza sales data into an interactive dashboard that makes it easier to understand business performance and identify important sales trends.

The dashboard consists of **two pages**, each designed to provide a different perspective on the sales data.

---

## 📊 Dashboard Pages

### 1️⃣ Sales Overview

The first page provides an overview of the overall sales performance and key business metrics.

It focuses on understanding:

* 💰 Overall sales performance
* 🛒 Order volume
* 🍕 Pizza sales
* 📈 Sales trends
* 📊 Key performance indicators

![Sales Overview](images/Screenshot%202026-09-10%20221833.png)

---

### 2️⃣ Product & Sales Analysis

The second page provides a more detailed analysis of pizza sales and product performance.

It helps explore:

* 🍕 Pizza performance
* 📦 Pizza size preferences
* 🏆 Best-selling products
* 📊 Sales distribution
* 🔎 Detailed sales insights

![Product Analysis](images/Screenshot%202026-09-10%20221851.png)

## 🧹 Data Preparation

The dataset was prepared and transformed using **Power Query** before being used in the dashboard.

The preparation process included:

* Cleaning the dataset
* Checking and correcting data types
* Handling data inconsistencies
* Transforming columns where necessary
* Preparing the data for analysis and visualization

## 📈 Key Metrics

The dashboard analyzes several important sales metrics, including:

* **Total Revenue**
* **Total Orders**
* **Total Pizzas Sold**
* **Average Order Value**
* **Sales Trends**
* **Product Performance**
* **Pizza Size Distribution**

These metrics provide a high-level view of sales performance while allowing deeper exploration through interactive visualizations.
